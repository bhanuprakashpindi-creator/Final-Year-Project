## Brand & Style

This design system embodies an institutional, tier-one financial intelligence posture designed for anti-money laundering (AML) investigators, federal regulatory bodies, and compliance risk officers. It synthesizes the visual discipline and density of enterprise developer tooling with the understated luxury of high-end fintech.

The interface projects absolute operational rigor, cryptographic authority, and analytical calm. It completely avoids gamified dashboards, amateur crypto aesthetics, or noisy neon overload. Instead, it deploys a disciplined dark luxury environment where deep naval blacks provide negative space for high-density, multi-hop forensic graphs and real-time transaction flows. Visual weight is concentrated on evidentiary status, entity clustering, and risk attribution.

Key stylistic pillars:
- **Restrained Cyber Precision:** Pure cyber-cyan and electric blue are deployed strictly as analytical anchors, active interactive states, and telemetry markers.
- **Forensic Ledger Hierarchy:** Clean typographic scale featuring neutral grotesk letterforms coupled with monospaced data structures for transaction hashes, wallet addresses, and timestamps.
- **Tactile Glass Layering:** Multi-tiered frosted surfaces with hairline structural borders provide visual separation without adding decorative bloat.

## Colors

The palette establishes an obsidian canvas calibrated to reduce eye strain during extended forensic investigations while enforcing unequivocal risk communication through strict semantic coding.

### Canvas & Surface Architecture
- **Base Canvas (`#080C14` / `#0B0F19`):** Ground level for the application window and un-elevated canvas areas.
- **Surface Elevation 1 (`#111827`):** Base container fill for modules, table shells, and navigation strips.
- **Surface Elevation 2 (`#1E293B`):** Interactive inputs, nested cards, and table header rows.
- **Surface Elevation 3 (`#334155`):** Hover states, popovers, flyout inspectors, and active segment tabs.

### Forensic Semantics & Signals
- **Primary Cyber Cyan (`#00F2FE`):** System focus rings, primary investigative triggers, active trace states, and directional path indicators.
- **Electric Blue (`#3B82F6`):** Secondary interactive actions, selected data nodes, verified entities, and standard structural links.
- **Licit / Compliant (`#10B981`):** Verified KYC counterparties, low-risk scoring (<15/100), clean provenance paths.
- **Elevated Warning (`#F59E0B`):** Unhosted mixers, sanctions proximity, moderate risk alerts (50–74/100).
- **Critical Illicit / Sanctions (`#EF4444`):** Specially Designated Nationals (SDN), darknet market drains, exploit payloads, critical risk (75+/100).

### Text & Hairline Tokens
- **High-Contrast Text (`#F8FAFC`):** Primary metrics, critical node labels, table headers.
- **Muted Text (`#94A3B8`):** Entity metadata, secondary identifiers, labels.
- **Hairline Border (`#1E293B`):** Default 1px card and cell division border.
- **Focus Border (`#334155`):** Elevated border for active inspections and card hovers.

## Typography

The typography couples the engineering clarity of `Geist` for interfaces and structural prose with `JetBrains Mono` for cryptographic identifiers.

### Implementation Rules
- **Cryptographic Hashes & Addresses:** Render all transaction digests (`txHash`), EVM addresses (`0x...`), and UTXO outpoints strictly in `data-mono-md` or `data-mono-sm` with tabular lining figures enabled (`tnum`).
- **Entity Classification Badges:** Apply `label-caps` in uppercase format with wide letter spacing (+0.08em) for regulatory tags (e.g., `OFAC-SDN`, `VASPs`, `MIXER`).
- **Data Densification:** In data tables, body copy shifts down to `body-md` and `body-sm` to maintain high screen real estate utility without compromising legibility.

## Layout & Spacing

The layout is architected around a fluid, dense analytical workspace calibrated for multi-pane investigations, graph workspaces, and deep data audit sheets.

### Workspace Architecture
- **Desktop (>= 1440px):** Full-bleed canvas driven by a continuous horizontal command bar (56px fixed height), optional collateral left filter rail (280px fixed width), flexible central canvas, and a collapsible forensic inspector drawer (380px fixed width).
- **Tablet (768px - 1439px):** Inspector drawers convert into slide-over sheets; 12-column fluid grid system with `gutter: 1rem` and `margin: 1.5rem`.
- **Mobile (< 768px):** Linear stacked view; complex visual graph canvases collapse to high-order chronological ledger lists; `margin: 1rem`.

### Spacing Principles
- Vertical rhythm strictly references an 8px base unit, descending to 4px (`space-xs`) exclusively for table row padding, badge insets, and micro-metric displays.
- Content groupings inside cards preserve tight contextual coupling: use `space-sm` between label and value, `space-md` between discrete metric clusters, and `space-lg` for macro section boundaries.

## Elevation & Depth

Visual hierarchy uses a refined glassmorphic surface system combined with razor-thin structural borders, rejecting standard drop shadows in favor of ambient luminescence and precise dark boundaries.

### Layer Stacking Model
- **Base Canvas (Level 0):** Pure dark space (`#080C14`), absorbing background reflections.
- **Glass Panel (Level 1):** Solid fill `#111827` at 70% opacity backed by `backdrop-filter: blur(16px)`. Framed with an ultra-thin border: `1px solid rgba(30, 41, 59, 0.65)`.
- **Raised Panel / Context Cards (Level 2):** Solid fill `#1E293B` at 80% opacity backed by `backdrop-filter: blur(20px)`. Border: `1px solid rgba(51, 65, 85, 0.75)`. Ambient outer glow: `0 8px 32px 0 rgba(0, 0, 0, 0.45)`.
- **Floating Modals & Flyouts (Level 3):** Solid fill `#0B0F19` at 95% opacity with an active cyber fringe: `0 0 0 1px rgba(0, 242, 254, 0.2), 0 20px 48px -8px rgba(0, 0, 0, 0.8)`.

### Border Discipline
Never introduce heavy borders. All visual containment must use strict 1px boundaries. When a card or node receives focus or hovers, the border brightens from `#1E293B` to `#334155` or an accent tint (`rgba(0, 242, 254, 0.4)`), avoiding abrupt layout shifts.

## Shapes

The interface balances sharp analytical precision with the polished feel of modern fintech via uniform curved profiles.

### Corner Radii Guidelines
- **Base Containers & Analysis Cards:** `rounded-xl` (1.0rem / 16px) creates a balanced, cohesive modular layout across high-density screens.
- **Interactive Controls (Inputs, Buttons, Segment Pickers):** `rounded-md` (0.5rem / 8px) ensures buttons maintain crisp, tool-like interaction targets.
- **Forensic Badges & Risk Tags:** `rounded-sm` (0.25rem / 4px) to retain an authoritative, ledger-like look rather than consumer "pill" tags.
- **Graph Nodes:** Strictly circular (`border-radius: 9999px`) for entities and wallet clusters, distinguishing them instantly from planar dashboard cards.

## Components

### Buttons
- **Primary Investigative:** High-performance solid cyan background (`#00F2FE`), text `#080C14` (`font-weight: 600`), hover state `#38BDF8` with a subtle glow: `box-shadow: 0 0 16px rgba(0, 242, 254, 0.35)`.
- **Secondary / Action:** Translucent slate background (`rgba(30, 41, 59, 0.6)`), text `#F8FAFC`, 1px border (`#334155`). On hover: background `#1E293B`, border `#475569`.
- **Destructive / Flag:** Deep crimson tint (`rgba(239, 68, 68, 0.12)`), text `#EF4444`, border `rgba(239, 68, 68, 0.35)`.

### High-Precision Data Tables
- **Header:** Sticky container, background `#0B0F19`, `label-caps` typography, text `#64748B`, 1px bottom border `#1E293B`.
- **Rows:** Minimum height 44px, alternating zebra layering prohibited; utilize hover highlights (`rgba(30, 41, 59, 0.4)`).
- **Cells:** Numeric and hash columns right-aligned with `data-mono-md`. Includes an inline copy trigger on hover with micro tooltip confirmation.

### Badges & Risk Status Indicators
- **High-Risk (Sanctions / Darknet):** Background `rgba(239, 68, 68, 0.15)`, text `#EF4444`, border `1px solid rgba(239, 68, 68, 0.4)`. Accompanied by a 6px static crimson indicator pip.
- **Licit (KYC Verified / Liquidity Pool):** Background `rgba(16, 185, 129, 0.15)`, text `#10B981`, border `1px solid rgba(16, 185, 129, 0.4)`.
- **Trace Node Badges:** Dynamic graph pill badges showcasing chain token glyphs (e.g., BTC, ETH, SOL) with monospace abbreviated address strings (`0x71C...4f8`).

### Input Fields & Search Bars
- **Omni-Search Bar:** Height 40px, background `#111827`, border `1px solid #1E293B`, text `#F8FAFC`, placeholder `#475569`. Displays hotkey badge `⌘K` aligned right in `data-mono-sm`.
- **Active State:** Border transitions to `#00F2FE`, supported by a subtle inward halo: `box-shadow: 0 0 0 1px #00F2FE`.

### Horizontal Navigation Bar
- Continuous glass ribbon fixed to canvas top. Height 56px, blur 20px, bottom border `1px solid #1E293B`.
- Displays real-time block propagation ticker, engine status indicator, breadcrumbs, forensic search query box, and agent clearance credentials.

### Interactive Graph Inspector Cards
- Floating HUD cards displaying entity risk breakdowns, flow volumes (USD & native token), counterparty breakdown lists, and immediate "Freeze Alert" or "Export Dossier" triggers.
